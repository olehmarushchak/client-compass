# Client Compass

Create a simple CRM web app for a small business to manage customers and deals.

Core features:

- Customer list (name, email, phone, company, notes)

- Add / edit / delete customers

- Deals/Pipeline board with stages: New Lead, Contacted, Proposal Sent, Won, Lost

- Ability to drag deals between stages (kanban-style)

- Each deal linked to a customer, with deal value and expected close date

- Simple dashboard showing: total customers, total deals, total pipeline value, deals won this month

- Basic search/filter for customers and deals

- Clean, modern UI with a sidebar navigation (Dashboard, Customers, Deals)

Use a simple database to persist data. Keep the design minimal and professional — suitable for a small business owner who isn't technical.
